infer-quota

A tiny Rust daemon and CLI that tracks Codex and Claude Code inference quota from existing logins, over a Unix socket.

Pieces

quotad
Collector.
quota
Read CLI.
quota-ctl
Accounts and refresh. It does not collect usage.

Why

A composable counterpart to CodexBar. No menu bar is required. Other tools can use the same socket.

Honesty

It would rather say unavailable than invent remaining tokens. It reuses existing Codex and Claude Code logins, and it never writes credential files.
