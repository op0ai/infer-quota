---
title: Compose
description: How the quota block stays one socket while menu bars, status lines, and orchestrators sit beside it.
---

infer-quota does one job: session reuse, a snapshot, the math, and a Unix socket. The public name fetchquota is that block — the quota and pool-math piece to reach for, small enough to drop into a larger workflow. [Examples](/examples) will document real composition patterns (web app, local process, a thread across pools, widget or menu bar, and other hosts) as they ship. Coming soon; `examples/` has no programs yet. Crate names stay put so a larger system can depend on a small surface.

Anything that needs the numbers — a menu bar, a tmux or Herdr status line, an MCP tool, a fleet orchestrator — should call [`quotad`](/quotad). It should not open Codex or Claude usage URLs on its own, and it should not become a second writer of `auth.json`.

| Piece                                            | Role next to this block                                                                                                                          |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `quota`                                          | Reference read client                                                                                                                            |
| `quota-ctl`                                      | Reference control client (accounts, refresh, secret pointers)                                                                                    |
| [CodexBar](https://github.com/steipete/CodexBar) | Separate macOS product. `quotad` can read its snapshot and history files when the live probe is down. It does not import CodexBar's provider set |
| A future renderer                                | `status`, `pace`, `watch` on the socket, then draw                                                                                               |
| A future MCP server for quota                    | The same methods as tools. Still not a collector                                                                                                 |

v0 ships no menu bar, no WidgetKit, no cookie-database scraper, and no MCP server inside the Rust workspace. Those can sit in other repositories and speak [protocol 1](/protocol).

Keep the daemon free of control-plane weight. OpenBao and the keychain stub are reached from `quota-ctl` / `quota-secrets`. `secret_ref` on an account is a pointer the daemon stores, not a vault client inside the poll loop.

When you add a client, ignore unknown JSON fields. Protocol 1 grows by optional fields. If the source did not publish a token budget, leave the window as `percent_only` and surface `unavailable` when the probe failed.
