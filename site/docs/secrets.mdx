Secret lookup lives in the `quota-secrets` crate. `quota-ctl` is the human CLI. `quotad` does not store passwords, API keys, or JWTs, and does not depend on this crate. The full note, including what must never be committed, is [`docs/SECRETS.md`](https://github.com/op0ai/infer-quota/blob/main/docs/SECRETS.md). This page follows that file.

## Lookup order

First hit wins:

1. **OpenBao** (optional, feature `openbao`, enabled by `quota-ctl`) — KV v2, for material the companion adds. A default `quotad` that only reuses existing CLI sessions does not need it. `cargo test` does not need a live server.
2. **OS keychain** — Linux secret-service on the session bus, or macOS Security.framework generic passwords. No session bus, or any other OS, returns `Unavailable` and the chain skips that backend.
3. **CLI files**, read-only, last. The first adapters read `$CODEX_HOME/auth.json` or `~/.codex/auth.json`, and `$CLAUDE_CONFIG_DIR/.credentials.json` or `~/.claude/.credentials.json`.

File writes are refused. `codex login` and Claude Code `/login` own those files.

Account metadata on the socket may include `secret_ref` `{ backend, path }`. That is a pointer. The bytes go through `quota-ctl secret put`.

## Local OpenBao

Dev only. The compose file is not a production vault. The token below is a dummy labelled as such.

```bash
docker compose -f docker-compose.dev.yml up -d
export QUOTA_OPENBAO_ADDR=http://127.0.0.1:8200
export QUOTA_OPENBAO_TOKEN=dev-only-not-for-prod
export QUOTA_OPENBAO_MOUNT=secret
export QUOTA_OPENBAO_PREFIX=quota
quota-ctl secret backends
export QUOTA_PUT=sk-example-not-real
quota-ctl secret put codex/work --from-env QUOTA_PUT
quota-ctl secret get codex/work
```

`secret get` prints `backend=` and `present=true`. It does not print the value.

OpenBao is added to the chain only when `QUOTA_OPENBAO_ADDR` and `QUOTA_OPENBAO_TOKEN` are both set and non-empty. Address without a token makes `secret backends`, `secret get`, and `secret put` fail with a config error instead of listing or skipping OpenBao.

`https://` uses rustls. `http://` is accepted for loopback (`127.0.0.1`, `localhost`, `::1`). Any other plain-HTTP host needs `QUOTA_OPENBAO_ALLOW_PLAINTEXT=1`, or the secrets commands fail with a config error. `QUOTA_OPENBAO_CA_FILE` is an optional PEM of extra CA certificates.

Default `cargo test --workspace` does not start OpenBao and does not dial port 8200.
