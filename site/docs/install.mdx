title: Install
description: Build quotad, quota, and quota-ctl from the infer-quota repository on macOS or Linux.
---

v0 is built from the [infer-quota](https://github.com/op0ai/infer-quota) repository. Rust **1.83+** (stable). macOS or Linux: each binary requires a Unix domain socket.

```bash
git clone https://github.com/op0ai/infer-quota
cd infer-quota
cargo build --release
```

Binaries:

```text
target/release/quotad
target/release/quota
target/release/quota-ctl
```

## Quickstart

In one terminal:

```bash
quotad run
```

`quotad` with no subcommand does the same thing. In another:

```bash
quota ping
quota status
quota status --json --provider codex
quota pace --provider claude
quota can-start --tokens 50000
quota watch
quota version
```

`quota ping` prints `pong` when the daemon is listening. If the client cannot connect, it prints the socket path and `quotad run --socket …`.

`cargo test --workspace` stays offline. Adapter tests use in-memory HTTP mocks and `fixtures/codexbar/`. OpenBao is optional and is not started by the test suite.

## Config

Missing config means defaults. Example: [`docs/config.example.json`](https://github.com/op0ai/infer-quota/blob/main/docs/config.example.json).

| Key                              | Default                                                        |
| -------------------------------- | -------------------------------------------------------------- |
| `history`                        | `false` (optional append-only JSONL of snapshots, not secrets) |
| `ring_capacity`                  | `128`                                                          |
| `refresh_min_secs`               | `30`                                                           |
| `refresh_max_secs`               | `300`                                                          |
| `http_timeout_secs`              | `10`                                                           |
| `enable_codex` / `enable_claude` | `true`                                                         |
| `enable_codexbar_files`          | `true`                                                         |

`quotad --config PATH` loads that file. Otherwise the path is `$XDG_CONFIG_HOME/quota/config.json`, or `~/.config/quota/config.json`.

## Docs site

The pages you are reading live in `site/` and build with [Blume](https://useblume.dev). From a checkout:

```bash
cd site
bun install
bun run dev
```

Node.js 22.12 or newer. `bun run build` writes static HTML to `site/dist/`. Deploy notes: [`site/DEPLOY.md`](https://github.com/op0ai/infer-quota/blob/main/site/DEPLOY.md). Agent entry points: [Agents](/agents).

Measured binary size and socket timings for one machine are in [`docs/BENCHMARKS.md`](https://github.com/op0ai/infer-quota/blob/main/docs/BENCHMARKS.md). Those figures are not portable and are not a latency claim about OpenAI or Anthropic.
